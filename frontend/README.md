# frontend

The admin web pages of assistantbot: Vue 3, Vite, and TypeScript, managed with pnpm. Run the `just frontend-*` recipes from the repository root.

See the admin guide, in [English](../docs/en/admin.md) or [简体中文](../docs/zh-CN/admin.md), and the Frontend section of [AGENTS.md](../AGENTS.md).
